# N=2/org=1 system harness

The first live system scenario covers the onboarding/access slice: bootstrap
one organization owner, invite a second person, enroll two independently keyed
installations, verify local access state, revoke one installation, and prove
that it fails closed while the other remains active. The exact representation
of administrative-transition evidence remains deferred.

After the onboarding/access gate passes, a separate scenario will place the
Brain above the federation permission gate and prove that reasoning sees only
authorized nodes and evidence. A later live gate will promote organization
ingest and batch receipts and prove full parity with the experimental pilot.
No executable placeholder is added because qualification forbids skipped tests.
