# Archive

Frozen history. Each file here is a dated design, sprint document or finished
implementation plan that no current document, test, tool, hash pin, CI step or
the operator playbook reads. They record what was decided and built at the
time; code, schemas and the current records say what is true now.

This folder is not an operator route. Start from the
[documentation index](../README.md) and the
[operations index](../operations/README.md), and never send a procedure,
recovery step or decision through a file here. Do not edit these files except
to repair a link that a move breaks.
